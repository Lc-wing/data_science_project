# Test Infrastructure — Plan 5 Phase A (`MacaoSpatialEquity`)

> **Owner**: E2E Testing Track Orchestrator (`e2e_orch_1`) — Dual-Track Architecture
> **Scope**: Opaque-box, requirement-driven 4-Tier E2E verification suite covering **all Phase A features (`A01–A16`)** of `PROJECT.md` and CS482 course requirements.

---

## 1. Test Philosophy

1. **100% Opaque-Box & Requirement-Driven**: Every test in `tests/e2e/` is derived strictly from authoritative user/course specifications (`ORIGINAL_REQUEST.md`, CS482 `Project-requirements`, `plans/plan_5_macao_facilities_ev_graph_dl.md`, `plans/00_review_report.md`) and `PROJECT.md § Interface Contracts`.
2. **Zero Internal Implementation Coupling**: No file under `tests/e2e/` may import `src/macao_equity/*` or read internal source modules for test assertions (enforced automatically via AST inspection). All verification operates strictly on user-facing deliverables (`.gpkg`, `.csv`, `.json`, `.graphml`, `.png`, `.tex`, `.bib`, `.pdf`, `.md`, `pyproject.toml`, CLI scripts).
3. **Independent Pure-Math Oracles**: Statistical and ML claims are NOT trusted on face value. `tests/e2e/e2e_lib/oracle.py` independently recomputes population-weighted Gini, parish-decomposed Theil's T (with $0\ln 0 = 0$), Benjamini–Hochberg FDR, Holm–Bonferroni step-down p-values, OLS with HC3 robust standard errors & VIF, Spearman rank correlation, tie-aware ROC-AUC, PR-AUC (average precision), Brier score, and Top-20% Hit Rate directly from frozen data artifacts.
4. **Mathematically Sound & Non-Prescriptive**:
   - Enforces provable invariants (2SFCA weighted supply conservation, 10→15 min support & total-supply monotonicity, weighted vs. unweighted EV dominance, Theil's T exact additivity, LISA quadrant sign theorem, per-fold naive prior `ROC-AUC == 0.5`).
   - Strictly avoids mathematically false traps (does NOT assert pointwise `acc15_i >= acc10_i`, does NOT assert `gini(15) <= gini(10)`, does NOT assert pooled OOF `naive_prior` `ROC-AUC == 0.5`, and NEVER prescribes empirical signs/p-values for falsifiable hypotheses H1–H3 per `00_review_report.md` C2/C7).
5. **Dual-Environment Runtime Resilience**: Core readers (`sqlite3` `?mode=ro` read-only URI GeoPackage GPB/ISO-WKB parser, streaming GraphML parser, strict JSON/CSV/TOML parsers, PNG `pHYs`/CRC32/`zlib` inspector, Poppler `pdfinfo`/`pdftotext -bbox` inspector) and math oracles use **pure Python 3.11 stdlib + system Poppler**, with optional secondary verification upgrades (`shapely`, `PIL`, `.venv` geospatial stack subprocesses) when `.venv` is present. This allows full verification both independently during the E2E Track and under `.venv/bin/pytest` in Final Milestone M5 without mutating frozen `.gpkg` files or touching `.venv/`.
6. **Empirical Discrimination Guarantee**: The E2E suite is continuously validated against both a realistic Macao-scale contract-conforming synthetic project root (must PASS 100% with `0 skipped`) and 15 single-invariant fault-injected mutations (every injected fault must FAIL with `pytest` exit code `1` and a targeted assertion message).

## 3. Test Architecture

### 3.1 Directory Layout (`tests/e2e/`)
```text
tests/e2e/
├── conftest.py                         # --project-root / MACAO_EQUITY_ROOT, sys.path bootstrap, session caches
├── e2e_lib/
│   ├── __init__.py                     # Package marker (never touches tests/__init__.py)
│   ├── contracts.py                    # Authoritative PROJECT.md paths, column sets, Macao UTM49N bounds, regexes
│   ├── readers.py                      # Pure-Python stdlib + Poppler readers (GPKG ?mode=ro, GraphML, PNG, PDF, CSV, strict JSON, TOML)
│   ├── oracle.py                       # Independent math oracles (Gini, Theil T, BH-FDR, Holm, OLS-HC3/VIF, Spearman, ROC/PR/Brier/Top20, point-in-polygon)
│   └── synthetic.py                    # Realistic Macao-scale valid synthetic project generator + 15 atomic single-fault mutators
├── test_tier1_feature_coverage.py      # Tier 1: 91 isolated requirement tests across A01–A16
├── test_tier2_boundary_corner.py       # Tier 2: 71 boundary, corner, anti-leakage & negative tests across 10 feature areas
├── test_tier3_cross_feature.py         # Tier 3: 12 pairwise cross-artifact & independent recomputation tests
├── test_tier4_real_world_scenarios.py  # Tier 4: 9 end-to-end stakeholder, Phase B & sandboxed CLI replay scenarios
└── test_e2e_self_validation.py         # Fast (<12s), double-recursion-guarded valid-PASS + 15-fault-FAIL self-validation
```

### 3.2 Target Root Resolution & Isolation
- `conftest.py` registers `--project-root <path>` with precedence:
  1. `--project-root` CLI flag
  2. `MACAO_EQUITY_ROOT` environment variable
  3. Default: the repository root that contains `tests/e2e/` (resolved from `tests/e2e/e2e_lib/contracts.py`, not a machine-specific checkout path)
- Run the suite from that root with `uv run pytest tests/e2e --project-root .` (or omit `--project-root` to use the default above). M2–M4 artifact tests stay in the suite and fail until those milestones exist.
- Read-only SQLite URI (`file:<path>?mode=ro`) guarantees reading frozen `.gpkg` artifacts NEVER writes `-wal`/`-shm` sidecars or alters mtimes/SHA-256 checksums.
- Dual-path handling for `data_provenance.json` (`outputs/metrics/data_provenance.json` preferred, fallback `data/raw/data_provenance.json`; if both exist, Tier 3 asserts agreement).
- Single-layer and multi-layer `.gpkg` support via `gpkg_contents WHERE data_type = 'features'`.

### 3.3 Key Technical Safeguards Built Into `e2e_lib/`
- **PNG 300-DPI Rounding**: `int(round(300 / 0.0254)) = 11811 px/m` decodes to `299.9994 DPI`. Assertions use `dpi >= 299.5` so matplotlib 300-DPI figures pass cleanly while 150/200-DPI figures fail.
- **PDF Fractional Main-Text Page Count**: Uses Poppler `pdftotext -bbox` XHTML word bounding boxes to segment Cover Page, Main Text, and Excluded Back Matter (`References`, `Contribution Statement`, `AI Usage Declaration`), computing exact fractional fill `(n_full_pages + last_page_fill)` and checking `[2.95, 3.85]` A4 pages alongside single-column horizontal flow and per-page A4 dimensions (`595.28 × 841.89 ± 3.5 pt`).
- **PDF Text Normalization & Context-Aware Framing**: Applies NFKC normalization, de-hyphenation, Unicode minus normalization (`−`/`–` → `-`), sentence-level negation awareness for correlational framing, and Cover/Contribution exemption for unknown student Name/ID placeholders while strictly banning `NaN`/`TODO`/`TBD_NUM`/`??` in analytical outputs and main text.
- **Safe Non-Mutating CLI Replay**: Tier 4 Scenario 5 copies `project_root` (excluding `.venv`, `.git`, `.agents`, caches) into `tmp_path/phase_a_replay_sandbox`, executes `scripts/run_phase_a.py --skip-download` with `cwd=sandbox`, `MACAO_EQUITY_ROOT=sandbox`, `PYTHONPATH=sandbox/src`, `MPLBACKEND=Agg`, `SOURCE_DATE_EPOCH=1763596800`, verifies exit code `0`, zero mutation of live `project_root/data/frozen/` hashes, valid sandbox `FREEZE_MANIFEST.json`, byte-identical frozen CSV/JSON contracts, and semantic/numerical determinism (`1e-9` on `.gpkg`, `1e-6` on tables/JSON) immune to GDAL `gpkg_contents.last_change` wall-clock timestamps.
- **Double Recursion Guard on Self-Validation**: `test_e2e_self_validation.py` checks `MACAO_E2E_IN_SELF_TEST == "1"` AND passes `--ignore .../test_e2e_self_validation.py` to child pytest processes; fault-injection checks strictly assert `returncode == 1` (`TESTS_FAILED`, NEVER `!= 0`) plus expected invariant error pattern.

## 5. Coverage Thresholds & Verification Gate Criteria

1. **Feature Coverage**: 100% of `A01–A16` covered; **≥ 5 isolated Tier 1 tests per feature** (91 total); **≥ 5 Tier 2 boundary/negative tests per feature area** (71 total across 10 areas); **12 pairwise Tier 3 cross-feature tests**; **≥ 8 Tier 4 real-world scenarios** (9 total).
2. **Opaque-Box Purity**: `0` imports of `macao_equity` or `src` anywhere inside `tests/e2e/` (AST-verified).
3. **Zero Silent Bypass**: `0` skipped tests (`skipped == 0`) on both valid synthetic validation and real Phase A verification; zero `assert True` / vacuous assertions.
4. **Synthetic Pass/Fail Discrimination**:
   - **Valid synthetic Macao project**: 100% PASS across all Tier 1–4 tests (`returncode == 0`, `0 failed`, `0 errors`, `0 skipped`).
   - **15 single-fault mutations** (wrong CRS `EPSG:4326`, 315 m `EPSG:8433` datum shift, swapped CEM lat/lon, maritime `Z26` included, zero-pop cell + 2% pop drift, 3× EV capacity double-count, EV ML feature leak, POI text EV leak, graph edge `t=0` / `>10` / asymmetric, dropped Taipa–Coloane edges, spatial fold empty positive class, Theil additivity broken, H2 diff/Holm broken, H3 pretest switching missing `SEM_ML`, tampered `FREEZE_MANIFEST.json` SHA-256, Table 1 numeric drift, and PDF out-of-budget / US Letter / 150-DPI figure): **15/15 MUST fail with `returncode == 1`** and targeted diagnostic output.
5. **E2E Track Strict AND Gate**: Requires independent PASS + `APPROVE` from 2 Reviewers, `APPROVE` from 2 empirical adversarial Challengers, and `CLEAN` from 1 non-skippable Intermediate Track Forensic Auditor before publishing `TEST_READY.md`.
