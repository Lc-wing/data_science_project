## 1. 研究问题与意义

**主研究问题：** 在澳门常见的天气情景下（晴朗温和 / 湿热 / 小雨 / 暴雨黄色信号），MUST 学生上课通勤的方式选择（步行、公交、轻轨、的士/网约车）会怎样变化？不同出发地（校内宿舍或氹仔、半岛、珠海跨境）的学生对天气的敏感度有没有差异？

| 假设 | 内容 | 检验方式 |
| --- | --- | --- |
| **H1** | 相比“晴朗温和”，“暴雨黄色信号”下选择步行的概率显著下降，选择的士/轻轨的概率上升 | 混合 logit 中天气属性的系数 + 预测选择概率的差值（带 CI） |
| **H2** | 天气效应的大小因出发地不同而不同（交互项） | 天气 × 出发地交互 + 似然比检验 |
| **H3** | 早上 9 点有课（时间压力）会放大天气效应 | 天气 × 时间压力交互 |

**受益者：** 学校（恶劣天气下的考勤和课程安排政策）、公交和轻轨运营方（雨天需求激增的线路）、学生（出门预留时间）。

**结论边界：** 陈述偏好反映的是 **意向**，不等同于实际行为。要用 RP 数据做效度对照，并在报告中说明假设偏差（hypothetical bias）。

## 2. 数据收集与准备

### 2.1 实验设计（`experimental-design` 技能）

| 属性 | 水平 |
| --- | --- |
| 天气 | 晴朗温和 24°C / 湿热（体感 ≥ 33°C）/ 小雨 / 暴雨黄色信号（4 个水平） |
| 时间压力 | 9:00 有课 / 时间比较灵活（2 个水平） |
| 公交 / 轻轨等候时间 | 5 / 10 / 20 分钟（3 个水平） |
| 的士 / 网约车可得性 | 容易叫到 / 难叫到且要等 15 分钟以上（2 个水平） |

- **设计：** 4×2×3×2 全因子共 48 个情景 → 用 **分式析因 / D-efficient 设计** 选出 16 个情景，分成 2 个区组（block），**每位受访者回答 8 个选择任务**，顺序随机化。
- **选项可得性：** 根据受访者真实的出发地设定可选项。例如半岛和珠海的学生不显示“步行”；校内学生不显示“的士”等。分析时使用可得选项集（availability set）。
- **另外单独提问（不放进 DCE）：** 遇到什么天气会选择“不去上课 / 申请网课”，降低社会期许偏差。
- **RP 部分：** 只问“过去一周”的通勤方式、出发地和常用出发时间段，用于 **效度检验**：比较 DCE 在“晴朗温和”情景下预测的方式占比和 RP 实际占比。

### 2.2 问卷实施
- 平台：问卷星 / Google Forms / 腾讯问卷，中英双语
- 渠道：MUST 学生群、宿舍、图书馆、课堂（取得老师同意后）
- 伦理：开头写明知情同意；完全匿名（不收集学号、姓名、手机号）；18 岁以上；可以随时退出
- 先找 5 人做预测试（pilot），确认题目理解和作答时长（目标 6–8 分钟）

### 2.3 样本量（`statistical-power` 技能）
- Orme 经验法则 `N ≥ 500c / (t · a)`，其中 c = 4（最大水平数），t = 8（任务数），a = 4（选项数），得到 `N ≥ 63`，**只够估计主效应**。
- H2/H3 需要估计交互项，并按出发地分组 → **目标 N = 150–200 人**（约 1,200–1,600 个选择观测）。
- 这只是经验法则，不是正式的功效分析。如果时间允许，可以用 pilot 数据得到的先验系数，做 **模拟功效分析**。

### 2.4 清洗
- 剔除作答时长 < 2 分钟的问卷、未通过注意力检测题的问卷、重复提交的问卷
- 报告样本的构成（学院、年级、出发地），并和 MUST 学生总体结构做对比（如果能拿到公开数据），说明代表性的局限
- **冻结数据：** `choices_long.csv`（每行 = 受访者 × 任务 × 选项）；5 折 `StratifiedGroupKFold` 的划分（按受访者分组）在阶段 A 就固定下来

### 2.5 天气情景的现实权重
- 用 SMG 的长期气候资料（各月雨日数、高温日数等）估计 4 种天气情景在学期内出现的频率，用于把选择概率加权成“学期平均方式占比”的情景分析。

## 阶段 A —— 最低要求（11/20–12/02）

### 3. 探索性数据分析（EDA）
- 样本描述表（明确报告独立受访者人数 N 与选择观测条数 M，区分分析单元）
- 不同天气情景下各方式的选择占比，按出发地分面（图 1）
- **配对效度检验（RP vs DCE“晴朗”情景）：** 因 RP 与 DCE 来自 **同一批受访者**（配对数据，非独立样本），不用常规独立 χ² 检验，而采用 **Stuart–Maxwell / Bhapkar 边际同质性检验** 配合 **受访者层面 cluster bootstrap** 给出各方式占比差值的 95% CI

### 4. 方法与理由

| 用途 | 方法 | 选择理由 |
| --- | --- | --- |
| H1（验证性） | 多项 logit（MNL）→ **面板混合 logit**（天气系数设为随机参数；可用 `xlogit` 或 `biogeme`） | 离散选择理论的标准方法；能处理重复选择和偏好异质性 |
| H2/H3（验证性） | 加入交互项 + 似然比检验（同一响应与相同观测行） | 直接检验预设交互假设 |
| 量化 | 预测选择概率的差值（例如暴雨 vs 晴朗时轻轨选择概率的变化，百分点），用 delta 法或 Krinsky–Robb 模拟得到 95% CI | 比系数更容易解读 |
| 机器学习 | XGBoost 多分类（特征 = 属性 + 个人特征），在 `StratifiedGroupKFold` 下和 MNL 比较 | 检验非线性模型能否提升预测 |

### 5. 评估、假设与不确定性
- **模型比较：** 在 **完全相同的观测行与选项集** 上比较对数似然、AIC/BIC、McFadden ρ²；按受访者分组 CV 的 log-loss、Macro-F1、Brier score。
- **假设检查：** MNL 的 IIA 假设（Hausman–McFadden 检验），这也是使用混合 logit 的理由之一。
- **多重比较：** 对各出发地子组的比较做 Holm 校正，只报告事先设定的子组。
- **局限：**
  - 陈述偏好的假设偏差
  - 便利抽样带来的选择偏差
  - 情景描述与真实天气体验之间的差距
  - 对结果的外推仅限于 MUST 学生

### 6. 结果与讨论
- **图 1：** 各天气情景下的方式占比（按出发地分面）
- **表 1：** 混合 logit 的关键系数 + 概率差值及 CI + 模型比较
- **图 2：** 天气 × 出发地的预测概率图，加上学期加权的情景分析
- **讨论：** 回答 H1–H3；RP 效度检验的结果；对学校和交通部门的建议；局限

## 阶段 B —— DL 附加模块（12/03–12/09，所有模型 ≤ 5B）

**输入：** 阶段 A 冻结的 `choices_long.csv` 和按受访者分组的 5 折 `StratifiedGroupKFold`。

### 路线 A（从零训练现代表格深度模型，约 1.5M–4M 参数）
- **模型：** **`FT-Transformer`（Feature Tokenizer + 4 层 Transformer Encoder，`d_token=192, n_heads=6, d_ff=384`，参数量约 1.5M–4M）**，将离散情景与个人特征映射为特征 token 后经自注意力建模高阶交互，在输出层对不可得选项执行 logit 遮蔽（`−∞`）后再做 softmax。
- **正则化与容量消融：** Weight Decay `1e-2`、Dropout 0.3、Cosine LR、验证集 Early Stopping，跑 5 个随机种子；同时保留 1 组轻量 **实体嵌入 MLP（~10k 参数）** 作容量对照，直接检验在 ~1,200–1,600 条选择样本上增大表格网络容量是提升精度还是引发过拟合。
- **事后校准：** 仅在内层验证折拟合 **Temperature Scaling**，在测试折报告 Log-loss、Macro-F1、**ECE**、Brier score，用配对 cluster bootstrap 估计与 MNL / 混合 Logit / XGBoost 的差值 CI。

### 路线 B（推荐充分利用 Colab 算力：预训练大模型微调，严格 ≤ 5B）
- **方案 B1（表格基础模型梯度微调）：** 使用 **`TabPFN`**（`FinetunedTabPFNClassifier`，参数量远低于 5B），在同一组分组折上对比 **默认零样本上下文学习（ICL）vs 梯度微调** 版本（使用前核实最新版本许可证与单次前向样本上限）。
- **方案 B2（4B TabLLM 行为选择微调，严格 ≤ 5B）：** 将每条冻结的 DCE 情景与受访者属性序列化为固定模板的中英文本，在 **`Qwen/Qwen3-4B-Instruct-2507`（4.0B，Apache-2.0）**（并可选与 **`Qwen/Qwen3-1.7B` (1.7B)** / **`Qwen/Qwen3-0.6B` (0.6B)** 做尺度消融）上接 4 类分类头并施加 **QLoRA / LoRA（`r=8` 或 `16`）** 在训练折受访者上微调；输出层严格执行 **可得选项 logit 遮蔽（`−∞`）**，并仅在内层验证折拟合 Temperature Scaling 校准。记录 `revision`、模板与随机种子（至少 3 种子）。

### 对比表（1 张小表）

| 模型（参数量，均 ≤ 5B） | Log-loss | Macro-F1 | ECE | Brier |
| --- | --- | --- | --- | --- |
| MNL / 混合 Logit / XGBoost（阶段 A） | | | | |
| `FT-Transformer` (~2M，+温度缩放，5 种子) | | | | |
| `TabPFN` 默认 / 梯度微调 | | | | |

**解读规则：** 在 1,500 条级别的表格行为选择数据上，4.0B LLM 或 FT-Transformer 未必优于混合 Logit / XGBoost。如实报告即可，并重点讨论 **预测/校准精度与行为可解释性之间的权衡**：混合 Logit 能直接给出边际效用与时间价值参数，而 4B 大模型仅提供预测概率与高算力开销。
