## 1. 研究问题与意义

**主研究问题：** 在 Steam 平台竞争日益白热化的 2018–2024 年发行队列中，游戏发售前可观测的定位因素（定价区间、中文/多语言本地化、题材饱和度、跨平台支持与开发商历史履历）与发售后口碑（经验贝叶斯好评率）及“商业突围”（累计评论 ≥ 500 且好评率 ≥ 80%）存在怎样的统计关联？在阶段 A 表格模型基础上，引入 **4.0B 预训练语言大模型** 理解商店页面简介文本，能否显著提升对 2024 年新发游戏突围概率与口碑的预测精度？

| 假设 | 内容 | 检验方式 |
| --- | --- | --- |
| **H1（验证性）** | 控制题材、定价与发行年份后，支持简体/繁体中文及多语言本地化、以及开发商既往高口碑履历与商业突围概率显著正相关 | 多元 Logistic 回归（同时报告绝对概率边际差与 OR、95% CI，按开发商聚类稳健标准误） |
| **H2（验证性）** | 在高度饱和题材（如普通 2D 平台/休闲）中，中等定价独立游戏比低价（< 5 USD）游戏具有更高的经验贝叶斯好评率与中位游玩时长（非线性关系） | OLS / 分位数回归（HC3 标准误）+ 题材 × 定价交互项（Holm 校正） |
| **H3（验证性，阶段 B 延伸）** | 结合 `Qwen3-Embedding-4B` / `Qwen3-4B`（≤ 5B）提取的商店页面简介语义表示，能在 2024 年新发游戏时间外测试集上显著提升突围预测 PR-AUC 与校准质量 | 严格模态消融（纯首发前表格 vs +TF-IDF vs +4.0B 文本微调）+ 配对 bootstrap CI |

**受益者：** 独立游戏开发团队（定价、中文/多语言本地化投入与商店文案定位）、中小发行商（立项与发行筛选评估）、玩家社区与数字内容平台研究者。

**结论边界：** 观察性横截面/队列数据，仅能识别发售前特征与市场结果的条件关联与预测能力，不代表“加上中文或提高定价就一定能成为爆款”的因果断言。

### 2.2 数据规模与变量
- **分析单元：** 单个独立发行的 Steam 游戏（不含 DLC、原声带与视频）
- **样本量：** 筛选 2018-01 至 2024-12 发售且非空商店简介的游戏约 **55,000–75,000 款**（其中评论数 ≥ 30 款用于口碑回归子集，约 **15,000–25,000 款**；全量队列用于商业突围二分类，明确报告每一步筛选前后样本量）。
- **目标变量：**
  - *主二分类目标（商业突围）：* 累计评论 ≥ 500 条 **且** 原始好评率 ≥ 80%（典型 Steam “特别好评 + 商业达标”门槛，约占全量 5%–10%，正负类不平衡故核心看 **PR-AUC**；另用 ≥ 200 条做阈值敏感性分析）；
  - *连续口碑目标（≥ 30 评论子集）：* 经验贝叶斯平滑好评率 `p_EB(i) = (Pos_i + α0) / (Pos_i + Neg_i + α0 + β0)`（先验超参 `α0, β0` **仅由训练集矩估计拟合**！）及 `log(1 + MedianPlaytime_i)`。
- **首发前预测变量：** 发售定价（含免费 F2P 指示项与价格分箱）、支持语言总数、是否支持简/繁中文与日/英/多语种、Windows/Mac/Linux 平台数、单人/多人/手柄/创意工坊官方特性、官方 Genre 多热编码、**截至该作发售日前 1 天该开发商已发行作品数及历史平均突围率（严格历史滚动计算，杜绝未来泄漏）**、发售月份/季度、商店简介字数与可读性特征。

### 2.3 清洗与预处理
1. 剔除发售日期缺失、尚未发售（Coming Soon）、测试 App 及重复条目；将所有价格统一核对为 USD。
2. 严查字段泄漏：**从输入矩阵中彻底移除** `Estimated owners`、`Peak CCU`、`Recommendations`、`Achievements`（若发售后新增）、`Positive`/`Negative`、`Metacritic`（发售后评分）及 `Playtime`。
3. **冻结切分（严格按发售时间外推，阶段 B 共用）：**
   - 训练集：2018–2022 发售游戏
   - 验证集：2023 发售游戏（调参、早停与概率校准）
   - 独立测试集：2024 发售游戏（仅最终评估一次；外加一份仅含“未在训练集出现过的新开发商”的冷启动子集指标）

### 4. 方法与理由

| 用途 | 方法 | 选择理由 |
| --- | --- | --- |
| H1（验证性） | 多元 Logistic 回归（开发商聚类稳健标准误），同时输出 **OR（95% CI）** 与 **平均边际概率差（百分点）** | 解释清晰，避免把 OR 误读为相对风险 |
| H2（验证性） | 在 ≥ 30 评论子集上运行 OLS（HC3 标准误）与中位数分位数回归（`statsmodels`），对题材 × 定价交互做 Holm 校正 | 稳健应对游玩时长与口碑分布的偏态和异方差 |
| 经典 ML 基线 | **LightGBM**（首发前表格特征）+ **LightGBM + TF-IDF SVD 文本基线**（SVD 仅在训练集拟合） | 构成强表格与传统词袋文本对照 |
| 解释 | TreeSHAP（背景样本仅从 2018–2022 训练集抽取，明示输出为突围概率或 log-odds 并核对 `model.classes_` 与可加性；仅说明模型行为） | 识别高阶非线性特征交互（如“免费 F2P × 多人联机”） |

### 5. 评估、假设与不确定性
- **分类指标（2024 测试集 + 冷启动新开发商子集）：** **PR-AUC**、ROC-AUC、Top-5% 筛选精准率（Precision@5%，对发行商选品最具实务意义）、Brier Score、ECE（验证折温度/Isotonic 校准后）。
- **回归指标：** MAE、RMSE、R²（带 bootstrap 95% CI）。
- **显著性检验：** 分类器间 PR-AUC / Brier 差异用配对 bootstrap 95% CI 与 DeLong 检验（ROC-AUC），多重比较用 Holm 校正。
- **核心局限：**
  - SteamSpy 统计存在抽样误差，且数据快照仅反映抓取时点状态；
  - 缺少发售后营销预算、主播推广（Twitch/B站曝光）与美术品质图像等关键未观测混杂因素——这直接决定了首发前纯元数据预测的天花板，必须在讨论中诚实说明。

## 阶段 B —— DL 附加模块（12/04–12/10，前提是通过 12/03 检查点，所有模型 ≤ 5B）

**输入：** 阶段 A **冻结** 的 2018–2024 队列、首发前特征表、`About the game` 商店简介文本及同一时间切分。

### 路线 A（从零训练多模态深度网络，约 5M–15M 参数）
- **模型：** **`FT-Transformer`（表格编码器）+ 2 层 `BiGRU-Attention`（商店简介文本编码器）** 融合网络（参数量约 **5M–15M**，`bf16` + Weight Decay `1e-2` + Dropout 0.3 + 验证集早停 + 温度缩放校准，跑 5 个随机种子，并做 1M vs 10M 容量消融）。

### 路线 B（推荐充分利用 Colab 算力：4B 语义/指令大模型多模态微调，严格 ≤ 5B）
1. **4B 多语言表征大模型 LoRA 微调（旗舰方案）：** 加载 **`Qwen/Qwen3-Embedding-4B`（4.0B，Apache-2.0，2560 维，支持 MRL 维度截断）**（并与 **`BAAI/bge-m3` 568M** 作尺度对照），输入商店页面简介 + 序列化首发前配置，在 2018–2022 训练集上做 **QLoRA / LoRA（`r=16`）** 联合分类/回归头微调，并在 2023 验证集上做早停与温度校准；
2. **4B 指令大模型 QLoRA 对比（可选）：** **`Qwen/Qwen3-4B-Instruct-2507`（4.0B，Apache-2.0）** 序列化“商店简介 + 定价/语言/类型/开发商履历”接分类头做 QLoRA 微调，对比其与 `Qwen3-Embedding-4B` 的表现；
3. **严格模态消融（2024 测试集 + 冷启动新开发商子集）：** 对比 (1) 纯表格 LightGBM vs (2) 表格 + TF-IDF vs (3) 表格 + 冻结 `Qwen3-Embedding-4B` vs (4) 端到端 LoRA 微调 4.0B 多模态模型；特别检验 **在冷启动新开发商子集上**（无历史履历可依赖时），4.0B 商店文案理解的增益是否大于老开发商子集！
4. **规范：** 记录 `transformers` / `peft` 版本、checkpoint `revision`、最大 token 截断长度与随机种子（至少 3 种子）。
