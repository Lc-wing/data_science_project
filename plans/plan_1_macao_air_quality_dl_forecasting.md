## 1. 研究问题与意义

**主研究问题：** 2022–2026 年间，氹仔（MUST 所在区）和澳门半岛的 PM2.5 是否存在系统性差异？这种差异与季节和风向条件有什么关联？只用当天已知的信息，能否可靠预测 **次日** PM2.5 日均值，以及是否会出现超标日？

| 假设 | 内容 | 检验方式 |
| --- | --- | --- |
| **H1** | 半岛站与氹仔站的日均 PM2.5 存在差异，且差异随季节变化 | 配对差值分析 + 季节分层 |
| **H2** | 冬季东北季风期、北风条件下的 PM2.5 显著高于其他条件（关联，不是因果） | 带 HAC 标准误的回归 |
| **H3** | 机器学习模型（LightGBM）的次日预测误差低于持续性基线和线性/SARIMAX 模型 | rolling-origin 回测 + HLN-DM 检验 |

**受益者：** MUST 学生（户外运动、通勤安排）、老人和哮喘患者等敏感人群、环保与卫生部门（预警阈值参考）。

**结论边界：** 本研究属于 **描述性 + 预测性** 研究，不对污染来源做因果归因。

### 2.2 数据规模与变量
- **分析单元：** 站点 × 日（阶段 A）；站点 × 小时序列（阶段 B）
- **样本量：** 2022-01 到 2026-10，约 1,760 天 × 2 个站点；小时级约 4.2 万条/站
- **目标变量：** 次日 PM2.5 日均值 \(y_{d+1}\)；二分类目标为次日是否超标（阈值按 SMG 现行 AQI 分级核实后确定，必须在报告里写明）
- **预测变量（只用 d 日及以前的信息）：** 当日及滞后 1–7 天的污染物日均值；当日气象统计量；风向的正余弦编码和风矢量 \(u, v\)；月份/星期的正余弦编码；假期标记；季风季节标记

### 2.3 清洗与预处理
1. 统一时区为 `Asia/Macau`，检查小时网格是否连续，**不要直接 dropna**（会破坏时间间隔）。
2. 缺失 ≤ 3 小时的用线性插值；某天缺失超过 25% 的小时，该天日均值记为缺失并在报告中列出数量；插值只能用过去和当天的数据。
3. 异常值：负值和长时间不变的“卡死”读数标记为传感器故障；真实的高污染事件保留。
4. **冻结切分（阶段 B 共用）：** 训练 2022-01 至 2024-12，验证 2025-01 至 2025-12，测试 2026-01 至 2026-10。测试集只在最后评估一次。
5. 标准化等预处理只在训练折上 fit。

### 4. 方法与理由

| 用途 | 方法 | 选择理由 |
| --- | --- | --- |
| H1 | 配对日差值 $\Delta_d = \text{PM2.5}_{\text{半岛}} - \text{PM2.5}_{\text{氹仔}}$：截距模型 + 季节回归 $\Delta_d \sim \text{季节}$，使用 **Newey–West (HAC) 标准误** 与 **block bootstrap 95% CI** | 日差值存在强时间自相关，常规独立同分布的配对 t 检验或 Wilcoxon 符号秩检验会低估标准误 |
| H2 | $\log(\text{PM2.5}_d) \sim$ 风向扇区 + 风速 + 雨量 + 湿度 + 季节 + 星期，HAC 标准误 | 可解释的条件关联；对数变换处理右偏 |
| H3 基线 | 持续性预测 $\hat y_{d+1}=y_d$；季节朴素预测 | 预测的最低参照 |
| H3 统计模型 | SARIMAX（带外生气象变量）或 Ridge 回归 | 线性基准 |
| H3 机器学习 | LightGBM（滞后、滚动统计、气象特征）；二分类用 LightGBM classifier，并做 class weight 处理 | 能捕捉非线性和交互作用 |
| 解释 | TreeSHAP（背景分布仅从训练折抽取，明示输出空间为回归原值或分类预测概率并核对 `model.classes_` 顺序与可加性；仅解释 **模型行为**，不作因果归因） | 和 H2 的回归系数互相印证 |

### 5. 评估、假设与不确定性
- **验证方式：** 在训练 + 验证期内做 expanding-window（rolling-origin）交叉验证来调参；测试期只评估一次。
- **回归指标：** MAE、RMSE、相对持续性基线的 Skill Score，并给出 95% bootstrap CI（用 block bootstrap 保留自相关结构）。
- **分类指标：** PR-AUC、F1、召回率（漏报的代价更高），以及 Brier score 和校准曲线。
- **显著性：** 用 HLN 修正的 Diebold–Mariano 检验比较模型，多组比较用 Holm 校正。
- **假设与局限：**
  - 站点代表性：MUST 校园不一定等同于氹仔站的情况
  - 2025 年起 AQI 定义有更新：只用浓度值，不用 AQI 指数
  - 非平稳性：交通电动化等政策变化
  - 气象协变量的分辨率限制

## 阶段 B —— DL 附加模块（12/03–12/09，前提是通过 12/03 检查点，所有模型 ≤ 5B）

**输入：** 阶段 A **冻结** 的清洗后小时序列、特征集和切分。

### 路线 A（推荐，从零训练中大规模深度时序模型，约 8M–20M 参数）
- **模型：** 深层多变量 **`PatchTST`** 或 **`iTransformer`**（亦可用深层残差 **Multi-Scale `1D-CNN + BiGRU + Self-Attention`** 对照）：输入过去 **168 小时（7 天）× $F$ 个特征** 的标准化窗口，联合输出次日 24 小时 PM2.5 序列，再聚合为次日日均值（直接与阶段 A 模型对齐）。
- **参考规模与正则化：** `d_model=512, n_heads=8, n_layers=6, d_ff=1024`，参数量约 **8M–20M**（Colab `bf16` 混合精度，AdamW + Weight Decay `1e-2` + CosineAnnealingLR + Dropout 0.25 + 验证集 Early Stopping）；同时做三档容量消融（**~0.5M vs ~3M vs ~15M**），科学检验在 ~4.2 万小时样本上继续放大从零训练模型的真实拐点。
- **不确定性：** MC Dropout（50 次前向采样，Colab GPU 秒级完成），**标为名义 90% 区间**，报告测试期经验覆盖率（PICP）与平均宽度（MPIW）。

### 路线 B（预训练大模型微调，120M–4.0B，严格 ≤ 5B）
- **专用时序基础模型：**
  - **`amazon/chronos-2`（120M，Apache-2.0）**：通过 AutoGluon `TimeSeriesPredictor` 启用 **LoRA 微调（`fine_tune=True`）**，原生利用两站点 cross-learning 与气象/日历协变量；
  - **`amazon/chronos-t5-large`（710M，Apache-2.0）**：在 Colab A100/L4 上做 **LoRA 微调**（对比零样本 vs LoRA 微调）；可选纳入 **`google/timesfm-2.5-200m-pytorch`（200M，Apache-2.0）** 零样本 + XReg 作外部基线。
- **4B 通用大语言模型跨模态微调对照（严格 ≤ 5B）：**
  - **`Qwen/Qwen3-4B-Instruct-2507`（4.0B，Apache-2.0，非思考高效指令版）**：将预测时点已知的过去 7 天站点观测统计 + 季风/风向/降水摘要序列化为结构化文本，外接回归/超标二分类头并施加 **QLoRA / LoRA（`r=16, alpha=32`）** 微调，正面检验“4B 通用大模型微调 vs 710M 专用时序大模型 vs LightGBM”的精度与算力性价比。
- **规范：** 记录每个模型 Hugging Face `revision`、AutoGluon / `peft` / `transformers` 版本、LoRA rank、步数、学习率与随机种子；分位数输出（q10–q90）统一标为 **名义 80% 区间** 并核验经验覆盖率。
