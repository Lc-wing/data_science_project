## 1. 研究问题与意义

**主研究问题：** 澳门各区居民步行 10–15 分钟能到达的公共设施（公园/休憩区、卫生中心、图书馆、公交站）和公共充电桩，分布有多不均衡？可达性较低的区域，是否和较高的长者比例、较高的人口密度相关？

| 假设 | 内容 | 检验方式 |
| --- | --- | --- |
| **H1** | 各类设施的步行可达性存在明显不平等，而且空间上集聚（存在 Low-Low 冷点） | 人口加权 Gini + bootstrap CI；Local Moran's I |
| **H2** | 公共充电桩可达性的不平等程度，和传统公共设施不同（可能更高） | 两类设施 Gini 差值的 bootstrap CI |
| **H3** | 控制人口密度后，长者比例较高的统计分区，可达性较低（关联） | 空间误差 / 空间滞后回归 |

**受益者：** 城市规划部门（优先补足的区域）、居民和长者、充电设施规划。

**结论边界：** 横截面的关联分析；可达性只基于“步行网络 + 设施位置（+ 容量）”，不包含设施质量和开放时间。

### 2.2 空间单元与变量
- **单元：** H3 第 9 级六边形格网（每格约 0.1 km²），只保留有人口的格网，约 250–400 个；回归分析在 DSEC 统计分区层面进行（避免分区人口估算带来的伪精度）。

### 4. 方法与理由

| 用途 | 方法 | 选择理由 |
| --- | --- | --- |
| H1（验证性） | Gini / Theil + bootstrap 95% CI；Global 和 Local Moran's I（999 次置换检验，并做 FDR 校正） | 标准的公平性和集聚分析 |
| H2（验证性） | 对“充电桩 Gini − 公园 Gini”等差值做 paired bootstrap 95% CI（对同一组格网重抽样） | 直接比较不同类型设施的不平等差异 |
| H3（验证性） | 统计分区层面：**预先同时设定** OLS（HC3 标准误）与空间误差/空间滞后模型（`spreg`），**并列报告**系数、95% CI 及残差 Moran's I（不凭诊断 p 值事后切换模型） | 兼顾常规线性基准与空间自相关稳健性，且在原普查分区上避免 dasymetric 伪重复 |
| 机器学习 | logistic 回归 / 随机森林：预测格网内 **是否有充电桩**（报告正样本格网数/总格网数；节点特征不含充电桩相关信息），使用 **空间分块 CV** | 描述充电桩的配置模式；为阶段 B 提供对照基线 |

### 5. 评估、假设与不确定性
- **H1–H3：** 置换检验的 p 值、bootstrap CI、回归诊断。
- **机器学习：** 空间分块 CV 下的 ROC-AUC、PR-AUC（充电桩格网可能占少数）、Brier score。
- **可塑性面积单元问题（MAUP）：** 对比 H3 第 8 级和第 9 级格网的结果。
- **局限：**
  - 分区人口估算假设建筑高度均匀，这在澳门的高层住宅区不成立（要重点说明）
  - 设施容量信息不完整
  - 没有考虑坡度、天桥和跨海通道
  - 生态谬误：分区层面的关联不能推到个人层面

## 阶段 B —— DL 附加模块（12/03–12/09，所有模型 ≤ 5B）

**输入：** 阶段 A 冻结的 `cells.gpkg`、`graph_edges.csv` 和 5 个空间分块。

### 路线 A（从零训练正则化图深度模型，约 0.2M–1.5M 参数）
- **任务：** 节点二分类（格网内是否有公共充电桩）。
- **模型：** 2 层 **`Graph Transformer`（`TransformerConv` / `GPSConv`）** 或多头 **`GATv2Conv`**（`hidden=128–256`，4–8 注意力头，LayerNorm + 残差连接 + DropEdge 0.3 + Dropout 0.5 + Weight Decay `1e-2`），参数量刻意控制在 **~0.2M–1.5M**（并对比 1 组 ~5k 轻量 `GraphSAGE` 做容量消融，防止 ~300 个节点的小图出现过平滑与过拟合）。
- **防止泄漏：** 节点特征只包含人口、建成环境和交通特征；**测试块里的节点标签在训练时要屏蔽**。跨训练块与测试块边界的边分别以 **“诱导式断开（inductive：训练期完全移除测试节点及跨界边）”** 和 **“直推式保留（transductive：训练期保留跨界边仅屏蔽测试标签）”** 两种设置各跑一次作敏感性分析，因为保留跨界边会让训练节点在消息传递中聚合到测试节点的特征（transductive 特征泄漏）。
- **评估：** 和阶段 A 的 logistic / 随机森林使用同一组空间分块；跑 10 个随机种子，报告均值 ± 标准差；指标为 ROC-AUC、PR-AUC，以及 **前 20% 高概率格网的命中率**。
- **解释与应用：** 用 GNNExplainer 或注意力权重 **定性** 展示邻近格网贡献（仅说明模型行为）；列出“预测概率高、目前无充电桩且 2SFCA 可达性低”的格网作为 **需现场核实的候选点**，并说明历史配置偏差。

### 路线 B（推荐充分利用 Colab 算力：4B 文本属性图大模型 LoRA 微调，严格 ≤ 5B）
- **多模态文本属性图（Text-Attributed Graph）：** 为每个 H3 格网汇总其内部 OSM POI 的名称、业态分布与街区结构文本（**严格过滤所有 EV / 充电桩 / 停车充电关键词以防目标泄漏**），在 Colab A100/L4（`bf16` / QLoRA）上加载旗舰表征大模型 **`Qwen/Qwen3-Embedding-4B`（4.0B，Apache-2.0，支持 MRL 可变维度与任务指令前缀）**，并与 **`BAAI/bge-m3`（568M，MIT）** 作跨规模对照：仅在训练空间块上对其注意力投影层施加 **QLoRA / LoRA 微调（`r=8`）**，输出语义向量经 MRL 截断或训练折内投影后与人口/路网数值特征融合，接入 **`GATv2Conv` / `TransformerConv`** 节点分类器。
- **四档模态与规模消融（同一空间分块 CV）：** 严格对比 (1) 纯数值特征 `GATv2` vs (2) +`BGE-M3` (568M) 嵌入 vs (3) +冻结 `Qwen3-Embedding-4B` (4.0B) vs (4) +LoRA 微调 `Qwen3-Embedding-4B` (4.0B)（记录 checkpoint `revision`、LoRA 配置与随机种子）。
